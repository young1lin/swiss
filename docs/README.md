# Docs

[`SPEC.md`](SPEC.md) is the front page of the one specification of swiss: what the system does
**now**, organised by area. Its §about says how to read and amend it; its chapter table and
anchor map lead into [`spec/`](spec/), one numbered chapter per area (`0001-product.md` …;
a chapter past 1000 lines is a directory of numbered parts, like `0012-memory/`), with the
decision log (ADR-001 …) as the last chapter. `assets/` holds the images the
repository README shows.
