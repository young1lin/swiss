# Code of conduct

This is a small project maintained in spare time. The rules are short:

- Be direct, be kind. Critique the code, the design, the decision — not the person.
- Assume good faith, then ask when something is unclear.
- No harassment, no discrimination, no personal attacks — in issues, pull requests, commit
  messages, reviews or anywhere else this project is discussed.
- Security reports go through [SECURITY.md](SECURITY.md), not public threads.

Anyone who breaks these rules will be asked to stop; if that does not work they will be
removed from the project's spaces. Concerns can be raised privately with the maintainer at
young1lin.
